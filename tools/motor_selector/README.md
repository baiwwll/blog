# 电机选型计算程序 v1.0

把「工况参数 → 需求转矩/转速/惯量/功率 → 在型号库里自动筛电机 → 逐项校核 → 出计算书」这一整套流程做成一个 Windows 桌面程序。

支持 8 类工况、8 种传动和 6 类电机，可计算需求、校核型号并导出计算书。

---

## 一、快速开始

### 0. Windows 下载版

从仓库的 [下载目录](../../downloads/) 下载 `MotorSelector-Windows-x64.zip`，完整解压到可写目录，进入 `MotorSelector` 文件夹后，双击 `电机选型程序.exe`。

此下载包为文件夹版，无需安装 Python。运行时必须保留 exe 旁的 `_internal/` 文件夹。首次启动会创建 `userdata/`，保存用户型号库、方案和报告。移动时请完整保留整个程序文件夹。

支持 Windows 10/11 64 位。

### 1. 直接运行源码
```powershell
cd tools/motor_selector
python main.py
```
需要 Python 3.9+（自带 tkinter，无需装任何第三方库）。

### 2. 重新打包
```powershell
cd tools/motor_selector

# 打包成文件夹并直接放到桌面「工作」（推荐）
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1 -Folder -OutDir "$env:USERPROFILE\Desktop\工作"

# 打包成文件夹，留在 dist\ 下
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1 -Folder

# 打包成单个 exe
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

### 3. 自测
```powershell
python -X utf8 tests\test_engine.py    # 计算引擎回归校核
python -X utf8 tests\test_library.py   # 型号库导入和导出
python -X utf8 tests\test_gui.py       # 界面冒烟测试（遍历全部工况/传动/惯量形状）
```

## 二、界面怎么用

左侧是参数区（**会按工况自动只显示相关参数**），右侧四个页签：

| 页签 | 内容 |
|---|---|
| **计算结果** | 需求汇总 + 全部中间量的逐步计算过程（每一项都写出公式） |
| **校核明细** | 选中电机方案的逐项校核（需求值 / 电机能力 / 余量 / 通过与否 / 说明） |
| **选型推荐** | 型号库中所有可行方案按匹配度排序，双击某行看它的校核明细 |
| **手填电机校核** | 手头已有一台电机时直接填参数复核（等价于原来 Excel 的用法） |

顶部按钮：
- **计算需求**：只算需求，不选型
- **自动选型**：在型号库里逐台校核 + 打分排序
- **导出计算书(HTML)**：一份可以直接发给别人的完整计算书（输入 + 过程 + 校核 + 推荐）
- **导出选型清单(CSV)**：Excel 可打开的推荐表
- **保存方案 / 打开方案**：JSON 存档，方便改一版存一版
- **惯量计算器**：按几何形状算转动惯量，一键填回主界面
- **型号库**：查看内置库、**导入你自己厂家的电机 CSV**、导出模板

参数一改就会自动重算（有 0.3 秒防抖），不需要反复点按钮。

## 三、和你那张 Excel 表的对应关系与差异（重要）

用你表里的数据（50 kg、μ=0.1、v=0.5 m/s、t加=0.1 s、每转移动量 0.05 m、η=0.8）跑，本程序的结果是：

| 项目 | 你的表格 | 本程序 | 说明 |
|---|---|---|---|
| 直动惯量 | 0.0031695 | 0.0031663 | 一致（J = m·(L/2π)²） |
| 摩擦力 | ~50 N | 49.03 N | 一致（μmg） |
| 加速力 | 250 N | 250 N | 一致（ma） |
| 需求转矩 | 0.5 N·m | 0.488 N·m | 一致（T = F·L/2πη） |
| 需求转速 | 未算 | 600 rpm | 新增（v/L×60） |
| **峰值转矩** | **没算** | **2.48 N·m** | ⚠ 原表只算了稳态转矩，**漏掉了加速转矩**。伺服/步进的选型瓶颈恰恰是这个值 |
| 电机功率 | 125 W（=加速力×速度） | 稳态 31 W / 峰值 156 W / 建议 187 W | ⚠ 原表用「加速力×速度」得 125 W，这个值既不是稳态功率也不是合理的峰值功率；本程序按普适的 P = T·ω 分稳态/峰值给出，再乘安全系数 |
| 惯量比 | 「无需校核」 | 6.33（含电机转子惯量 0.0005） | ⚠ 原表因为减速比填 0 就跳过了；惯量比是伺服/步进能不能整定好的关键指标，必须校核 |
| 转矩校核 | 需求转矩 0.5 < 额定 3，通过 | 峰值 2.48×1.5 = 3.72 < 最大转矩 6.6，通过 | 结论相同，但本程序对**加速工况**校核 |
| 速度校核 | 不加减速机 通过 | 600 rpm < 1450 rpm，通过 | 一致 |

**结论：原表结论方向是对的（这台电机够用），但原表漏算加速转矩和惯量比，在加速快、惯量大的场合会选出偏小的电机。** 本程序把这些补齐了。

## 四、我帮你补上了哪些参数，为什么需要

原表有 30 项，本程序扩到 60+ 项，按「为什么必须要」分三类：

### A. 影响计算正确性，缺了就一定算错（必须填）

| 新增参数 | 为什么必须 |
|---|---|
| **减速比 i**（原表填 0 会算错） | i = 电机转速/负载转速，直驱填 **1**，不能填 0；所有折算（转矩 ÷i、惯量 ÷i²）都依赖它 |
| **传动形式** | 决定「力 → 转矩」的换算路径：丝杆用导程、带轮用 π·节圆直径、齿条用模数周长，效率也完全不同 |
| **传动效率 η** | 直接进分母（T = F·L/2πη）。丝杆效率 0.4 和 0.9，电机差一倍多 |
| **加速时间 / 减速时间 / 匀速时间 / 停留时间** | 四段时间决定 RMS 有效转矩与占空比，是伺服热校核的依据；只给「加速时间」不够 |
| **负载惯量**（旋转工况） | 转盘/辊筒类工况，惯量往往比转矩更决定电机大小；程序内置实心圆柱/圆环/长方体/细杆/球 5 种形状公式 + 惯量计算器 |
| **丝杆导程 / 直径 / 长度 / 效率** | 丝杆自身惯量 J = πρld⁴/32（长丝杆惯量能超过负载）、自锁校核、长径比校核都要用 |
| **重力/倾角/配重** | 垂直和倾斜工况的重力分量是主要负载，配重会显著改变结果 |
| **轴承摩擦转矩 / 不平衡重力矩**（旋转工况） | 转台偏心、轴承阻力是旋转工况的稳态负载来源 |
| **定位精度** | 决定要不要校核步距角分辨率、编码器分辨率、减速机背隙 |
| **步进电机的矩频曲线** | 步进转矩随转速急剧下降，不看曲线只看「保持转矩」一定会选小 |

### B. 决定「选出来能不能用」的工程判据（建议填）

| 新增参数 | 作用 |
|---|---|
| **供电条件**（AC380/AC220/DC48/DC24…） | 按电压筛掉不能用的型号 |
| **电机类型要求** | 限定只在伺服 / 步进 / 异步 / 无刷 / 直线里选 |
| **转矩安全系数** | 默认 1.5。需求转矩先乘系数再和电机能力比 |
| **功率安全系数** | 默认 1.2 |
| **惯量比上限** | 默认按类型：伺服 10 / 步进 5 / 无刷 10 / 有刷 20 / 异步 100 |
| **允许加装减速机** | 勾上后程序会自动搜索合适速比（含内置减速机库的额定/峰值转矩、允许输入转速、背隙校核） |
| **最大电机功率** | 限制成本/机座号 |
| **行程** | 校验「加减速距离是否放得下」，避免写了达不到的速度 |
| **外部恒定阻力 / 外部阻力矩** | 切削力、张力、弹簧力等工艺载荷 |

### C. 覆盖工况所必需的专用参数

- **输送机**：皮带/承载件折算质量
- **卷绕/放卷**：最小卷径、最大卷径、张力、卷筒质量/惯量（变卷径要同时满足「大卷径转矩点」和「小卷径转速点」，程序会两个点都校核）
- **旋转件**：5 种形状的几何尺寸

## 五、计算原理（每一步都能在「计算结果」页看到公式）

```
1) 运动学
   直线：a = v / t加          n负载 = v / L × 60       L = 每转移动量
   旋转：α = 2π(n/60) / t加
   折算：n电机 = n负载 × i    α电机 = α负载 × i

2) 静力学（负载侧阻力）
   水平   F = μmg + F外
   倾斜   F = μmg·cosθ + mg·sinθ + F外
   垂直   F = mg - m配重·g + μmg + F外   （下压工况重力取负）
   输送   F = μ(m料+m带)g·cosθ + (m料+m带)g·sinθ + F外
   旋转   T = 轴承摩擦 + 外力矩 + 不平衡重力矩
   卷绕   T = 张力 × D/2（D 取最大卷径）

3) 转矩
   T负载(电机侧) = F·L / (2π·η·i)      （负载侧转矩 ÷ i）
   T加速        = (J负载/i² + J联轴器 + J电机) × α电机
   T峰          = T负载 + T加速
   T有效(RMS)   = √(ΣT²t / Σt)  按 加速/匀速/减速/停留 四段加权

4) 惯量
   直动折算  J = m·(L/2π)²
   实心圆柱  J = m·r²/2        圆环 J = m(r₁²+r₂²)/2
   长方体    J = m(a²+b²)/12   细杆绕端 J = m·l²/3
   丝杆      J = π·ρ·l·d⁴/32
   折算到电机轴 J' = J负载侧 / i²

5) 功率
   P稳态 = T负载·ω       P峰 = T峰·ω       P建议 = max(P峰, P稳态×功率安全系数)
   （注：常用经验式 P = F·v 只适用于匀速直线简单场合，加速工况会严重低估）
```

## 六、校核项（按电机类型自动切换）

| 电机类型 | 校核项 |
|---|---|
| 通用异步电机 | 转速、最大转矩（默认 2.2×额定）、连续转矩、功率、惯量比；提示需配变频器与低速散热 |
| 步进电机 | 转速（矩频曲线覆盖）、**动态转矩（曲线插值）**、惯量比、步距分辨率、低频共振区提示、丢步余量提示 |
| 交流伺服 | 最高转速、峰值转矩（过载倍数）、连续有效转矩（RMS）、惯量比、编码器分辨率、峰值转矩持续时间提示 |
| 直流无刷 / 有刷 | 转速、峰值转矩、连续转矩、功率、惯量比 |
| 直线电机 | 最高速度、峰值推力、连续推力、负载/动子质量比、行程提示 |
| 减速机 | 额定输出转矩、峰值输出转矩、允许输入转速、速比范围、**背隙折算定位误差** |

可行性 = 所有「必校项」全部通过；匹配度评分 = 各项余量的加权分（余量太小扣分，余量太浪费也扣分，惯性比越接近上限越扣分，减速比越大越扣分，功率越大越扣分）。

## 七、型号库与 CSV 导入

内置库：**73 台电机**（异步 4/6 极、伺服标准型与大惯量型、两相混合式步进含闭环、无刷、有刷、直线电机）+ **95 台减速机**（行星、谐波、蜗轮蜗杆、摆线针轮、通用）。

> ⚠ **内置数据是按行业常见规格整理的「典型参数」，用于方案阶段量级估算，不是任何一家厂商的正式样本。** 正式设计/下单前请：
> 1. 点「型号库 → 导出 CSV 模板」；
> 2. 按模板把你要用的厂家型号参数填进去；
> 3. 「导入电机 CSV」追加到用户库（存在 `userdata/motors_user.csv`，可反复导入）；
> 4. 重新「自动选型」。

CSV 列名中英文都认（中文表头如 `类型,型号,额定功率W,额定转速rpm,额定转矩Nm,峰值转矩Nm,转子惯量kgm2,电压,矩频曲线,编码器,...`）。步进电机的矩频曲线写成 `转速:转矩` 逗号分隔，例如 `0:2.8,300:2.2,600:1.4,900:0.8`。

## 九、免责与使用建议

1. 内置型号库为典型参数，**必须用厂家样本复核**后再下单。
2. 程序算的是**电磁与传动**层面的匹配；电机散热、驱动器电流余量、安装尺寸、防护等级、成本、线缆长度、电磁制动器、安全回路需要另行确认。
3. 伺服/步进方案请务必关注**惯量比**与**有效(RMS)转矩**这两个指标，它们比峰值转矩更容易被忽略、也更容易在现场出问题。
4. 垂直提升/大倾角工况请确认停机保位方式（电磁制动器 / 自锁蜗轮蜗杆 / 配重），程序只做提示不做结构设计。
5. 结论页给出的每一行「余量」都是 能力/需求 的比值：**1.2~2.5 是舒适区**，低于 1.2 偏紧，高于 3 一般意味着选大了（成本、体积、惯量都吃亏）。
