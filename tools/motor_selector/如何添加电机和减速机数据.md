# 以后怎么添加电机 / 减速机数据

**结论先说：99% 的情况不用改代码，也不用找我 —— 在程序里点几下就能加，加完自动生效。**

---

## 一、最常用：导入 CSV（改数据不改代码）

### 操作步骤

1. 双击 `电机选型程序.exe`
2. 点顶部 **「型号库」** 按钮
3. 点 **「导出电机模板」** / **「导出减速机模板」** → 得到一个带示例行的 CSV
4. 用 **Excel 打开**（注意：用 Excel 直接保存要选 **CSV UTF-8**，否则中文乱码）
5. 照着示例行的格式，把你的电机/减速机一行一台填进去（表头别动，单位别换）
6. 回到「型号库」窗口，点 **「导入电机 CSV」** 或 **「导入减速机 CSV」**
7. 提示「新增 N 台」→ 关掉窗口，点 **「自动选型」**，新数据就已经参与选型了

数据存在哪里：`工作\userdata\motors_user.csv`（电机）、`工作\userdata\gearboxes_user.csv`（减速机）。
程序每次启动自动把「内置库 + 用户库」合并使用，用户库里的 **「来源」列会显示「用户导入」**，方便区分。

### 几个要点

| 事项 | 说明 |
|---|---|
| 导入是「追加」不是「覆盖」 | 同类型 + 同型号会自动去重；重复导入同一份文件不会产生重复行 |
| 想改某台电机的参数 | 在导出的 CSV 里改完重新导入是不行的（同型号会被去重跳过）。**直接在 `userdata\motors_user.csv` 里改**，或者把「型号」改个名字再导入 |
| 想删掉某条 | 编辑 `工作\userdata\motors_user.csv`，删掉那一行即可（或用「打开用户库文件夹」按钮） |
| 内置库会被污染吗 | 不会。内置库写在代码里，用户库是独立文件，点「清空用户库」就能全部还原 |
| 换电脑 | 把 `userdata` 文件夹一起拷过去即可 |
| 表头语言 | 中文表头、英文表头都认；单位一律用 **W / rpm / N·m / kg·m² / m / m/s** |

### 电机 CSV 列说明

| 中文表头 | 英文列名 | 必填? | 说明 |
|---|---|---|---|
| 类型 | kind | ✅ | 只能填：`异步电机` `步进电机` `伺服电机` `直流无刷` `直流有刷` `直线电机` |
| 型号 | model | ✅ | 自己看得懂就行，会显示在选型结果里 |
| 额定功率W | rated_power | 异步/直流必填 | 伺服可填可不填（按转矩校核） |
| 额定转速rpm | rated_rpm | ✅ | |
| 最高转速rpm | max_rpm | 建议 | 不填按类型默认（伺服额定×1.5，异步=额定） |
| 额定转矩Nm | rated_torque | ✅ | 异步/直流：连续转矩；伺服：连续转矩；步进：填保持转矩 |
| 最大转矩Nm | max_torque | 异步填 | 异步电机的最大转矩（一般 2.0~2.2×额定） |
| 峰值转矩Nm | peak_torque | 伺服填 | 伺服峰值转矩（一般 3×额定）。不填则按 3×额定估算 |
| 转子惯量kgm2 | inertia | ✅ | 惯量比校核全靠它，样本上一定有 |
| 保持转矩Nm | holding_torque | 步进填 | |
| 步距角deg | step_angle | 步进填 | 一般 1.8 |
| 矩频曲线 | torque_curve | **步进必填** | 格式 `转速:转矩` 逗号分隔，例：`0:2.8,300:2.2,600:1.4,900:0.8,1200:0.45`。不填会被当成恒转矩，**会选小** |
| 电压 | voltage | 建议 | 例：`AC380V 三相`、`AC220V 单相`、`DC24V`。用于按供电筛选 |
| 编码器 | encoder | 伺服建议 | 例：`23bit 绝对值`，程序会算每脉冲位移校核定位精度 |
| 连续推力N / 峰值推力N | cont_force / peak_force | 直线电机填 | |
| 动子质量kg / 最高速度ms | mover_mass / max_speed | 直线电机填 | 动子质量会计入加速推力 |
| 重量kg | weight | 可空 | 仅展示 |
| 效率 | efficiency | 可空 | 仅展示，不参与计算 |
| 备注 | notes | 可空 | 会出现在计算书里，建议写样本来源 |

### 减速机 CSV 列说明

| 中文表头 | 英文列名 | 必填? | 说明 |
|---|---|---|---|
| 类型 | kind | ✅ | 例：`行星减速机` `谐波减速机` `蜗轮蜗杆减速机` |
| 型号 | model | ✅ | |
| 减速比 | ratio | ✅ | **每个速比写一行**（i=10 和 i=25 是两行） |
| 额定输出转矩Nm | rated_torque | ✅ | 校核减速机能不能扛住负载转矩 |
| 峰值输出转矩Nm | peak_torque | 建议 | 不填按额定×2 |
| 效率 | efficiency | ✅ | 行星 0.94~0.96；蜗轮蜗杆 0.5~0.8；谐波 0.7~0.85 |
| 背隙arcmin | backlash_arcmin | 建议 | 会折算成定位误差，跟「定位精度要求」比对 |
| 允许输入转速rpm | max_input_rpm | ✅ | 校核电机转速是否超限 |
| 输入轴惯量kgm2 | inertia | 建议 | 折算到电机轴的附加惯量 |
| 重量kg | weight | 可空 | 仅展示 |
| 备注 | notes | 可空 | |

## 二、什么时候需要找我（改代码）

只有下面这几种情况需要动代码 / 重新打包：

| 需求 | 处理方式 |
|---|---|
| **想让新数据成为"内置库"**，换台电脑、发给同事时也自带 | 把 CSV 发我，我写进 `core\database.py` 的 `builtin_motors()` / `builtin_gearboxes()`，重新打包给你 |
| **整批厂家样本**（几十上百个型号，PDF 或 Excel 目录） | 发我，我批量整理成 CSV 并核对单位 |
| **增加新的电机类型**（如永磁同步、力矩电机、空心杯电机） | 需要改校核逻辑（`core\selector.py`）+ 类型枚举（`core\entities.py`） |
| **增加新的工况 / 传动**（如曲柄连杆、凸轮、多轴同步） | 需要改 `core\mechanics.py` 加受力模型 |
| **改默认值**（默认安全系数、默认惯量比上限、默认电压等） | 改 `core\entities.py` 的 `LoadCase` 默认值，或直接告诉我 |
| **改界面**（加字段、改布局、加新按钮、换字体） | 改 `main.py` |

自己动手也行，改完在 `motor_selector` 目录跑：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1 -Folder -OutDir "$env:USERPROFILE\Desktop\工作"
```

想验证没改坏，跑这三个自测（全绿就放心）：

```powershell
python tests\test_engine.py    # 计算引擎（含 Excel 数据回归）
python tests\test_gui.py       # 界面（遍历 8 工况 × 8 传动 × 6 惯量形状）
python tests\test_library.py   # 型号库导入导出链路
```

## 三、判断"加进去的数据对不对"的三个办法

1. **看「型号库」窗口**：新导入的条目会出现，来源列显示 `用户导入`。
2. **手填校核页对账**：把新电机的参数填进「手填电机校核」页，看校核明细里的「电机能力」是否等于样本值。
3. **看计算书**：选中方案导出 HTML，里面有完整公式和逐项校核，可以直接发给别人复核。

## 四、最省事的做法

如果你懒得整理 CSV，**直接把样本截图 / Excel / PDF 发我，说一句"加进去"**，我来：
1. 整理成规范 CSV（核对单位、补矩频曲线、标来源）
2. 导入验证 + 跑一遍自测
3. 重新打包到桌面「工作」，你双击就能用

一次给我 10~50 个型号是最舒服的批量。
